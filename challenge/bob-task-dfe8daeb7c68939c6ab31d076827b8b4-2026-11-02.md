# Concept: Agent Builder

## Idea
A way for employees to build their own AI agents without code, based on the company's own knowledge and tools.
The form factor is open. It could be a plugin, an app, or a feature inside an existing platform.

## Who it's for
Non-technical employees in an organization.

## Core model: Input → Processing → Output

**Input**
- The user describes what they will give the agent on each run.
- The agent can connect to company tools and data sources (connectors), such as a calendar. Which ones are available depends on the organization.

**Processing**
- The agent is grounded in company material, such as procedures, templates and guidelines.
- During the build, the user is asked which material the agent should rely on.
- The user defines in natural language how the agent should work.

**Output**
- The user defines the result they expect: a document, a presentation, a calendar event, an email draft, a table, a summary, or other formats depending on connectors.

## Feedback loop
- After each result, the user rates it and can add a comment.
- The rating is used to refine the agent's processing, through suggested changes the user can accept.
- The agent improves over repeated runs.
